# Telegram Lead Hunter

Автоматизированная система поиска клиентов в Telegram-чатах для IT-фрилансера.

## Возможности

- **Мониторинг чатов в реальном времени** — читает сообщения из чатов, где состоит рабочий аккаунт
- **Двухуровневая фильтрация лидов** — ключевые слова + AI-классификация
- **AI-диалоги с клиентами** — AI общается с клиентами по техникам продаж
- **Холодные лиды из чатов** — AI-детектор латентного спроса (бизнес без сайта, ручные процессы)
- **2GIS холодный обход** — импорт CSV, AI-генерация первого сообщения, отправка после ручного одобрения
- **Уведомления на основной аккаунт** — бот присылает лидов с кнопками "Написать" / "Игнорировать"
- **Контроль цены** — вы указываете цену, AI продолжает переговоры
- **AI-рассылка по чатам** — 2-3 раза в сутки в заданное время (± случайный сдвиг) AI генерирует новое рекламное сообщение, соблюдая правила конкретного чата
- **Десктоп-интерфейс** (`main_gui.py`) — список всех чатов аккаунта: что читать, куда делать рассылку, правила чата, время
- **Анти-бан** — задержки, лимиты, прогрев аккаунта, имитация набора текста

## Запуск

Два режима (запускать только ОДИН из них, не оба сразу — конфликт Telegram-сессии):

```bash
python main_gui.py   # окно управления чатами + вся система (для работы на своём ПК)
python main.py       # без окна, только консоль (для VPS)
```

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Получение API ключей

**Telegram API (для рабочего аккаунта):**
1. Перейдите на https://my.telegram.org
2. "API development tools" → создайте приложение
3. Получите `api_id` и `api_hash`

**Бот уведомлений:**
1. Напишите @BotFather в Telegram
2. Создайте бота → получите токен
3. Узнайте свой Telegram ID через @userinfobot

**DeepSeek API:**
1. https://platform.deepseek.com/api_keys
2. Создайте ключ (бесплатно, платите за использование)

**OpenAI API:**
1. https://platform.openai.com/api-keys
2. Создайте ключ

### 3. Настройка конфигурации

```bash
cp .env.example .env
```

Заполните `.env` файл:
```env
TG_API_ID=12345678
TG_API_HASH=ваш_hash
TG_PHONE=+79991234567
NOTIF_BOT_TOKEN=123456:ABC-DEF
OWNER_TG_ID=123456789
OPENAI_API_KEY=sk-...
DEEPSEEK_API_KEY=sk-...
```

### 4. Запуск

```bash
python main_gui.py   # с окном управления чатами
# или
python main.py       # без окна (VPS)
```

При первом запуске Telethon попросит код подтверждения Telegram (вводится в консоли).

### 5. Управление через бот

Напишите боту уведомлений (в Telegram):

- `/start` — проверка работы
- `/addchat @chat_username` — вступить в чат и начать мониторинг
- `/chats` — список отслеживаемых чатов
- `/status` — статус системы
- `/warmup_done` — завершить прогрев аккаунта
- `/price 5 350000` — указать цену для диалога #5
- `/stats` — статистика лидов
- `/help` — все команды

## AI-рассылка по чатам

1. Запустите `python main_gui.py`
2. Нажмите «Обновить список чатов из Telegram» — появятся все группы аккаунта
3. Выберите чат, включите «Рассылка», вставьте правила чата (или отметьте «Правил нет»), укажите время: `10:00, 19:30`
4. «Тест: сгенерировать сообщение» — посмотреть текст без отправки
5. «Сохранить» — рассылка активна

Защита от бана: без заполненных правил рассылка НЕ отправляется. Если правила запрещают публикацию сейчас (например «реклама только по средам») — AI пропускает отправку и сообщает в бот. Каждая отправка проходит общие анти-бан лимиты. Время срабатывания сдвигается случайно до +25 минут.

## Архитектура

```
main.py              — точка входа (headless, для VPS)
main_gui.py          — точка входа с окном управления чатами (Tkinter)
config.py            — конфигурация и AI промпты
database.py          — SQLite (чаты, лиды, диалоги, статистика)
anti_ban.py          — защита от бана (задержки, лимиты, прогрев)
ai_engine.py         — AI-провайдеры (классификация, диалоги, рассылки)
lead_detector.py     — фильтрация (ключевые слова → AI)
user_client.py       — Telethon клиент (мониторинг, отправка, диалоги)
notification_bot.py  — aiogram бот (уведомления, управление)
scheduler.py         — рассылки по расписанию (статичные + AI)
cold_outreach.py     — 2GIS холодный обход
gis_importer.py      — импорт CSV из 2GIS
```

## Поток работы

1. Рабочий аккаунт состоит в чатах → мониторит новые сообщения в реальном времени
2. Каждое сообщение проходит фильтрацию: возраст → длина → ключевые слова → AI
3. Найденный лид → уведомление вам через бота с кнопками
4. Вы нажимаете "Написать" → AI начинает диалог с клиентом
5. Клиент описывает задачу → бот уведомляет вас
6. Вы указываете цену (`/price N сумма`) → AI продолжает переговоры
7. AI закрывает сделку или передаёт диалог вам

## Анти-бан

- **Прогрев:** первые 3 дня — только чтение, без отправки (настраивается)
- **Лимиты:** 10 сообщений/час, 50/день (настраивается)
- **Задержки:** 30-300 сек между действиями + имитация набора текста
- **Рандомизация:** AI генерирует варианты текста для рассылки

## Стоимость

~$4-6/мес при 10 чатах (DeepSeek для классификации + GPT-4o-mini для диалогов).

## Важно

- Рассылка в чаты нарушает ToS Telegram — риск бана аккаунта
- Начинайте с мониторинга + ответов на лиды, рассылку добавляйте осторожно
- Не используйте основной аккаунт для рассылки
- Храните `.env` и `.session` файлы в безопасности
